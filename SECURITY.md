# Security Policy

## Scope & Philosophy

**Confitext** is an Obsidian visual presentation masking layer designed as a shoulder-surfing deterrent.

It alters how characters appear visually on screen inside the Obsidian editor window. **It does NOT encrypt notes or protect underlying Markdown files on disk.**

Anyone with access to your file system, synced backups, Git repositories, clipboard, or developer inspection tools can read the note contents directly.

## Reporting a Vulnerability

If you discover a genuine security vulnerability or safety issue within Confitext (such as unexpected network requests, memory safety issues, or unauthorized clipboard operations), please report it responsibly:

1. Open an issue on GitHub marked as security inquiry.
2. Please provide reproduction steps and environment details.
3. We will acknowledge receipt within 48 hours and work with you on a resolution.
