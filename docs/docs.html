Confitext Documentation

The official technical reference and user guide for Confitext: an animated, non-destructive visual privacy layer built for Obsidian with CodeMirror 6.

1. Introduction & Architectural Guarantees

Confitext is designed exclusively as an in-editor visual privacy shield and shoulder-surfing deterrent. Whether working in open offices, flights, libraries, or coffee shops, it obfuscates character presentation on physical screens during active typing and reading.

Core Architectural Rule: Confitext operates solely in-memory via CodeMirror 6's virtualized screen presentation layer (Decoration.replace). Your underlying Markdown files (.md) on disk are never modified, encrypted, or altered.

When you select text, copy paragraphs, or sync your vault with Git, Obsidian Sync, or iCloud, clean plain-text Markdown is preserved with zero data corruption risk.

2. Installation Guide

Option A: Obsidian Community Plugin (Recommended)

  1. Open Obsidian Settings → Community plugins.
  2. Ensure "Restricted mode" is turned Off.
  3. Click Browse and search for Confitext.
  4. Click Install, then click Enable.
  5. Or open directly via the obsidian URI: obsidian://show-plugin?id=confitext.

Option B: Manual Installation from GitHub Release

  1. Download the latest release zip from GitHub Releases.
  2. Extract the three files (main.js, manifest.json, styles.css) into your vault under:
    <YourVault>/.obsidian/plugins/confitext/
  3. Restart Obsidian or reload plugins in Settings, then toggle Confitext on.

3. Quick Start & Operating Modes

Confitext features three primary global operating states accessible from the status bar, ribbon icon, command palette, or settings:

  • Masking (Default): Active visual privacy veil. Completed words, targeted terms, or sensitive patterns are masked with dynamic glyphs.
  • Revealed: All text is temporarily displayed in cleartext for public presentations, proofreading, or screenshots.
  • Paused: Masking is suspended until explicitly resumed.

Instant Panic Conceal

Press the panic hotkey or trigger Confitext: Panic hide & mask all text from the Command Palette. Confitext immediately collapses all selections, sets global mode to Masking, and obscures every open editor pane in 0 milliseconds.

4. Typing Triggers (Rhythm Customization)

In Settings → Privacy Shield & Scope, choose how aggressively text conceals while drafting:

  • Word Mode (Default): Words remain readable while typing. As soon as you hit space or punctuation (.,;:!?), the completed word scrambles into digital glyphs.
  • Line Mode: The entire current line you are editing stays visible and readable. Pressing Enter or moving the cursor to another line engages the veil over the previous line.
  • Paragraph Mode: Keeps the current paragraph readable while writing. The block is only masked once a blank line gap is formed below it.

5. Targeted Masking & Frontmatter Integration

If you don't want full-page masking, switch Masking Scope to Targeted Words Only:

  • Global Remembered Words: Add terms in Settings or right-click any word/selection in the editor and click Confitext: Mask "..." globally.
  • Note-Specific Words: Define words in the note's YAML frontmatter:
    --- confitext-masked-words: - ProjectTitan - InternalBudget - Alice ---

6. Sensitive Data Shield (Pattern & PII Masking)

Confitext includes an automated real-time regex engine to conceal sensitive data patterns without requiring exact keyword definitions:

  • Email Addresses: Obfuscates standard email addresses (e.g., user@company.com).
  • API Keys & Tokens: Detects JWTs, OpenAI tokens (sk-...), AWS keys (AKIA...), and GitHub personal access tokens.
  • Credit Card Numbers: Redacts 13 to 19 digit Visa, MasterCard, Amex, and Discover account numbers.
  • Phone Numbers: Conceals international and domestic formats.
  • IP Addresses: Shields IPv4 and IPv6 addresses.
  • Custom Regex Manager: Add user-defined regular expressions in Settings with safe i and u flag compilation.

7. In-Place Reveals & Hover Glance

  • Selection Reveal: Drag your cursor or select text with Shift + Arrow keys. Highlighted words reveal themselves instantly in cleartext for editing.
  • Cursor Reveal: Placing the text caret inside a word reveals that individual word.
  • Quick Glance (Hover Reveal): When enabled in Settings, resting the mouse cursor over any masked word for a configurable delay (default 500ms) temporarily displays the cleartext word. Moving the mouse restores the mask.

8. macOS Sequoia & PC Desktop Pro Suite

Tailored specifically for desktop setups, macOS Sequoia, and Windows workstations:

  • Hold Esc to Peek Cleartext: Press and hold the physical Escape key on macOS or Windows to momentarily reveal all text for a quick glance. Releasing Escape instantly re-engages privacy masking. Includes automatic focus-loss defense on Alt-Tab / Cmd-Tab.
  • Multi-Monitor Edge Blur: Listens for mouse departure across window boundaries or OS blur events to automatically engage masking when switching focus between monitors.
  • Typography Ligature Support: Leverages OpenType font-feature-settings: "liga" 1, "calt" 1 on SF Mono, JetBrains Mono, and Cascadia Code.
  • Custom Hover Delay: 200ms (Instant), 350ms (Snappy), 500ms (Balanced), 800ms (Relaxed), or 1200ms (Deliberate).

9. iOS & Android Touch Shield & Ergonomics

Built for mobile devices, foldables, and tablets:

  • Platform Settings Filtering: Settings are automatically tailored to the device. Desktop-only options (hover peek, physical Esc peek, tab header buttons) are hidden on mobile to avoid visual clutter.
  • Predictive Keyboard Suggestion Animations: Selecting words from mobile virtual keyboard suggestions (Gboard, Samsung Keyboard, iOS QuickType) triggers smooth Matrix scramble animations automatically without requiring trailing whitespace.
  • Caret Line Click Reveal: Tapping directly on any masked word unmasks it immediately in cleartext for editing.
  • Circular Corner Radius Comfort: Generous 24px–26px horizontal inset padding ensures that settings cards, text, toggle switches, and buttons sit comfortably away from curved Android/iOS screen corners.
  • Zero-Latency Startup Masking: High-speed synchronous local cache eliminates plain-text exposure flashes during app cold boot.
  • Haptic Touch Feedback: Subtle vibration confirmation on mode toggles, panic conceals, and selection reveals using the HTML5 Vibration API.
  • Battery-Saver 30 FPS Cap: Limits animation requestAnimationFrame loops to ~33ms, saving battery life and preventing CPU heat.

10. Note & Folder Exclusions

  • Exclude a Note via Frontmatter: Add confitext: false to any note's YAML frontmatter. Confitext will completely disable masking for that document.
  • Exclude Entire Folders: Specify directory paths in Settings (e.g., Public, Work/Shared). Any note inside these folders remains in cleartext.

11. Markdown Syntax Preservation

Confitext tokenizes Markdown intelligently. It preserves headers, lists, checkboxes, blockquotes, code blocks (```), inline code (`code`), LaTeX math formulas ($...$), URLs, and footnotes so the document structure remains navigable.

12. Custom Glyphs, Palettes & Theming

Confitext allows deep visual personalization so the privacy veil aligns with your aesthetic preferences:

  • 5 Built-in Glyph Palettes: Choose from Matrix Code (0 1 Ξ Ж ░ ▒ ▓ ⌁ ⟁ ⌂ ⵙ Ϟ), Braille Script (⠁ ⠃ ⠉ ⠙ ⠑ ⠋ ⠛), Cyber Runes (᚛ ᚜ ᚠ ᚡ ᚢ ᚣ ᚤ ᚥ), Morse Code (• − ⬝ — ·), and Geometric Shapes (▲ ▼ ◆ ◇ ○ ● ◈ ■ □).
  • Custom User Glyphs: Define your own custom string of Unicode characters in Settings. Confitext will randomly distribute your characters across masked words using a deterministic per-word hashing algorithm.
  • Dynamic Color Themes: Select from Matrix Luminous Green, Cyberpunk Cyan, Amethyst Purple, Amber Terminal, Crimson Alert, or Monochrome Stealth.
  • Phosphor Glow & Mask Opacity: Toggle a subtle CRT phosphor glow around characters and adjust mask opacity from 0.1 to 1.0 (default 0.85).

13. Frequently Asked Questions

Does Confitext encrypt my files on disk?

No. Confitext is an in-editor visual privacy deterrent designed to shield your display from human observers (shoulder surfing). It does not encrypt files on disk. For cryptographic data protection at rest, use full-disk encryption (FileVault, BitLocker, LUKS) or encrypted storage vaults.

Does Confitext make any network calls?

Zero. Confitext contains no network calls, no analytics, no telemetry, and requires no account. It runs 100% locally on your machine.

How do I copy text from a masked note?

Simply highlight the text and press Ctrl+C or Cmd+C. Because masking is purely a visual decoration, the copied text is standard, readable Markdown.
